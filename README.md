# Fut-Pinball
⚽ Fut Pinball – ¡El fútbol como nunca lo jugaste! Fut Pinball es un videojuego de fútbol que combina la pasión por este deporte con la diversión y la dinámica de un pinball. Elegí tu equipo favorito, entrá a la cancha y competí para marcar goles, superar a tus rivales y demostrar quién manda en el campo de juego.  Creado por: Martino Segovia
